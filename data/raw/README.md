# Raw Source Texts

- **`train/`**: Official Python documentation, manually split into 5 pedagogical stages:
  - Stage 1: Introduction, basic types, control flow
  - Stage 2: Practical guides (files, regex, functional programming)
  - Stage 3: Language reference (formal syntax, semantics)
  - Stage 4: Standard library (OS, serialization, testing)
  - Stage 5: Advanced topics (concurrency, networking, C integration)

- **`val/`**: Python tutorials from w3schools.com — used for unbiased validation

> 📚 This structure enables experiments on "curriculum learning", though results show it's ineffective for non-repetitive text.
